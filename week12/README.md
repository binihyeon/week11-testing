# 12주차 데이터 분석

## 데이터

- **출처:** 수업 배포 실습 파일 `week12_files.zip` 내 `scores_2026.csv` (교육용 가공 데이터)
데이터 크기: 원본 데이터는 114행, 5열로 구성되어 있다.

열 설명:

class: 학생이 속한 반

name: 학생 이름

subject: 과목명

score: 학생 점수

(나머지 열은 원본 CSV의 열 구성을 따름)

- 빈 칸 처리 방법: 점수(score)가 비어 있는 행은 분석에 필요한 점수 정보가 없으므로 제거하였다. 이를 통해 평균 계산 시 결측값으로 인한 오류나 왜곡을 방지하고, 유효한 점수 데이터를 기준으로 분석할 수 있도록 하였다.
- **중복 처리:** 모든 열 값이 완전히 같은 행은 한 행만 남긴다. 같은 기록이 반복되어 계산에 중복 반영되는 것을 방지한다.
- **공백 처리:** 반과 과목 문자열의 앞뒤 공백을 제거해 동일 범주가 서로 다른 값으로 인식되지 않게 한다.
- **이상값 처리:** 점수가 0 미만 또는 100 초과인 행은 범위 밖 값으로 판단해 제외한다.

## 실행
