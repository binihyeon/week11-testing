# 12주차 데이터 분석

## 데이터

- **출처:** 수업 배포 실습 파일 `week12_files.zip` 내 `scores_2026.csv` (교육용 가공 데이터)
- **원본 크기:** 114행, 5열 (헤더 제외 데이터 114행)
- **열 설명:** 학번(문자 식별자), 이름(문자), 반(문자; 1반/2반), 과목(수학/영어/프로그래밍), 점수(0~100 범위의 점수)
- **빈 칸 처리:** 점수가 비어 있는 행은 분석할 점수가 없으므로 제거한다. 임의로 점수를 채우면 실제 관측값과 구분할 수 없고 평균을 왜곡할 수 있기 때문이다.
- **중복 처리:** 모든 열 값이 완전히 같은 행은 한 행만 남긴다. 같은 기록이 반복되어 계산에 중복 반영되는 것을 방지한다.
- **공백 처리:** 반과 과목 문자열의 앞뒤 공백을 제거해 동일 범주가 서로 다른 값으로 인식되지 않게 한다.
- **이상값 처리:** 점수가 0 미만 또는 100 초과인 행은 범위 밖 값으로 판단해 제외한다.

## 실행

`week12` 폴더에서:

```bash
pip install pandas pytest
python analysis.py
pytest -q
```
